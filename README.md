# Бот учёта оплаты Minecraft-сервера

Полная инструкция для человека с нулевым опытом. Иди по шагам по порядку, ничего не пропускай.

---

## Шаг 1. Создать бота через @BotFather

1. Открой Telegram, в поиске найди **@BotFather** (это официальный бот Telegram, у него синяя галочка).
2. Напиши ему `/start`, потом `/newbot`.
3. Он спросит **имя бота** — это то, что будет отображаться в чате (например: `Оплата Minecraft`).
4. Потом спросит **username бота** — он обязательно должен заканчиваться на `bot` (например: `mc_payment_bot`). Если имя занято — придумай другое.
5. BotFather пришлёт сообщение с токеном — строка вида:
   ```
   123456789:AAHk3jd8...длинная строка...
   ```
   Это и есть `BOT_TOKEN`. **Никому его не показывай** — это как пароль от бота.

---

## Шаг 2. Узнать свой Telegram ID

1. Найди в Telegram бота **@userinfobot**.
2. Напиши ему `/start`.
3. Он пришлёт твой `Id` — цифры вроде `987654321`. Это твой `ADMIN_ID`.
4. Свой username (без @) ты и так знаешь — он в настройках Telegram (Settings → Username). Это `ADMIN_USERNAME`.

## Шаг 3. Скачать код бота

Все файлы бота лежат ниже в этом чате. Скачай их и сложи в **одну папку** на компьютере, сохраняя структуру:

```
mc_bot/

├── texts.py

└── handlers/
    ├── __init__.py
    ├── start.py
    ├── registration.py
    ├── menu.py
    └── admin.py
```

## Шаг 4. Настроить файл .env

1. Скопируй файл `.env.example` и переименуй копию в `.env` (именно `.env`, без `.example`).
2. Открой `.env` в блокноте и заполни:
   - `BOT_TOKEN` — токен из Шага 1
   - `ADMIN_ID` — твой ID из Шага 2
   - `ADMIN_USERNAME` — твой username из Шага 2
   - `SERVER_IP`, `SERVER_PORT` — данные твоего сервера superhub.host
   - `MODS_LINK` — ссылка на архив с модами (выложи его на Яндекс.Диск или Google Drive и скопируй ссылку)
   - `CARD_NUMBER` — номер карты, куда игроки могут скидывать деньги
   - `YOOMONEY_WALLET` — номер твоего кошелька ЮMoney (просто цифры, для отображения игрокам)
   - `YOOMONEY_TOKEN` — пока оставь пустым, получим в Шаге 7

## Шаг 5. Запустить бота (на Railway — бесплатно, без своего компьютера)

Проще всего для новичка — Railway, он держит бота включённым 24/7 без твоего участия.

1. Зайди на **https://railway.app** и зарегистрируйся (можно через GitHub-аккаунт — если его нет, создай на **https://github.com**, это бесплатно и займёт 2 минуты).
2. Загрузи папку `mc_bot` на GitHub:
   - Зайди на github.com → New repository → назови его, например, `mc-bot` → Create.
   - На странице репозитория нажми **Add file → Upload files** и перетащи туда все файлы и папку `handlers/` из Шага 3.
   - Внизу нажми **Commit changes**.
   - ⚠️ Файл `.env` **не загружай** на GitHub — там секретный токен. Загружай только `.env.example`.
3. Вернись на Railway → **New Project → Deploy from GitHub repo** → выбери свой репозиторий `mc-bot`.
4. Railway начнёт деплой автоматически (он увидит `Procfile` и `requirements.txt`).
5. Зайди в настройки проекта → вкладка **Variables** → добавь туда все переменные из своего `.env` файла (по одной: имя переменной = значение). Это и заменяет файл `.env` на сервере.
6. После добавления переменных Railway сам перезапустит бота. Зайди во вкладку **Deployments → View Logs** — если видишь строки вроде `Start polling` — бот работает.

## Шаг 6. Проверить, что бот жив

Найди своего бота в Telegram по username (из Шага 1), напиши `/start`. Бот попросит ФИО и ник — это нормально, ты как раз первый регистрирующийся игрок.

## Шаг 7. Получить токен ЮMoney (для автосписания платежей)

Это можно сделать позже, бот и без этого работает — платежи тогда подтверждаются вручную командой `/confirm`.

1. Зайди на **https://yoomoney.ru** и авторизуйся в своём кошельке.
2. Перейди по ссылке: `https://yoomoney.ru/oauth/authorize?client_id=ВАШ_CLIENT_ID&response_type=code&redirect_uri=ВАШ_REDIRECT&scope=operation-history`
   Для новичка проще другой путь:
   - Зайди в раздел **Настройки → API и уведомления** в личном кабинете ЮMoney.
   - Создай приложение (можно указать любое название, например `mc bot`), в правах доступа отметь **operation-history** (история операций).
   - После создания приложения ЮMoney выдаст `access_token` — длинную строку.
3. Вставь эту строку в переменную `YOOMONEY_TOKEN` (в `.env` локально или в Railway → Variables).
4. Попроси игроков при переводе указывать своё **ФИО** в комментарии к платежу — так бот сможет его распознать. Учти: автоматическое сопоставление по ФИО работает не идеально (не все переводы ЮMoney передают имя отправителя), так что для надёжности проверяй платежи и подтверждай вручную командой `/confirm @username сумма`, если бот не подхватил перевод сам.

## Шаг 8. Добавить самого себя как первого игрока

Вариант А (проще всего):
1. Напиши своему боту `/start`.
2. Введи своё ФИО и ник в Minecraft — заявка автоматически придёт тебе же в личку (ты администратор).
3. Нажми кнопку **✅ Подтвердить** под этим сообщением.

Готово — ты первый зарегистрированный игрок, тебе доступно главное меню.

---

## Команды администратора (только тебе, из аккаунта с ADMIN_ID)

| Команда | Что делает |
|---|---|
| `/setplayers 6` | Вручную задать число активных игроков (иначе считается автоматически) |
| `/confirm @username 100` | Вручную засчитать платёж 100₽ игроку |
| `/ban @username причина` | Забанить игрока (заблокировать доступ в боте) |
| `/unban @username` | Разбанить игрока |
| `/addplayer @username ник Имя Фамилия` | Добавить и сразу подтвердить игрока (работает, только если игрок уже писал боту хоть раз) |
| `/removeplayer @username` | Удалить игрока из базы |

## Важные ограничения (честно, чтобы не было сюрпризов)

- **Автоопределение платежей по ФИО** через ЮMoney не 100% надёжно — API не всегда передаёт имя отправителя. Считай это дополнительным удобством, а не гарантией; периодически проверяй вручную через `/confirm`.
- **Автоматическое исключение "не заходил 7 дней"** бот не делает сам — для этого нужна была бы интеграция с логами самого Minecraft-сервера, чего нет в текущей версии. Это действие остаётся на администратора вручную.
- **Кик/бан на самом сервере** бот не делает — он только считает деньги и шлёт уведомления. Банить игрока в игре всё ещё нужно тебе вручную (через RCON/консоль superhub.host).
